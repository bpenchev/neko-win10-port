# Neko for Windows 10

A working modern port of the classic Windows desktop cat — **Neko** 🐱  
Originally popular on Windows 3.1 and 95, Neko is a tiny animated cat that chases your mouse pointer across the screen.

This version has been **rebuilt from source** and updated to run on **Windows 10 and 11** without emulators or compatibility layers.

---

## 📦 What's Included

- `neko98.exe` – The main cat animation application
- `NekoCFG.exe` – The configuration tool to change behavior, speed, and style

---

## ✅ How to Use

1. [Download the latest release](https://github.com/bpenchev/neko-win10-port/tree/v1.0/release) from the Releases tab
2. Extract the ZIP file anywhere
3. Make sure **both** `neko98.exe` and `NekoCFG.exe` are in the **same folder**
4. Run `neko98.exe`
5. To configure, right-click the system tray icon or run `NekoCFG.exe`

---

## 🖥️ System Requirements

- Windows 10 or 11 (64-bit)
- No installation needed

---

## 🛠️ Rebuilding from Source

If you’d like to build the application yourself:

1. Open `source/Neko.sln` in Visual Studio (2022 or newer recommended)
2. Make sure both `neko98` and `NekoCFG` projects are included
3. Build the solution in **Release x64** mode

---

## 📚 Background

Neko (Japanese for "cat") was originally written by Naoshi Wada. This port preserves the behavior and charm of the original, while making it compatible with modern systems.

Special thanks to the open-source community for preserving this nostalgic gem.
